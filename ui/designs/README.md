# 37QAG 界面设计 · 三套风格方案

> 产出于 2026-09-26 · 设计静态原型，未改动任何核心代码。

## 方案总览

| 方案 | 定位 | 目录 | 主题 id |
|---|---|---|---|
| **A · 素笺** | 宣纸白 + 墨字 + 朱砂印 + 靛青批注（浅色信笺风，安静克制） | `A-sujian/` | `sujian-paper` |
| **B · 深空控制台** | 深空蓝黑 + 冰青 HUD + 琥珀仪表（暗色任务控制台风，信息密度高） | `B-deep-space/` | `deep-space-console` |
| **C · 暖房** | 奶油米 + 陶土橘 + 鼠尾草绿（暖色居家风，圆润亲和） | `C-warm-room/` | `warm-room` |

每套目录内两个文件：

- `prototype.html` —— 自包含静态原型（无外部依赖、无网络请求，双击即可预览）
- `theme.json` —— 可直接导入的主题文件（走现有「导入主题文件」通道）

## 原型覆盖范围

三套共用同一信息架构（同一布局、同一交互、同一演示数据，仅视觉系统不同），便于横向对比：

- **会话列表**：搜索（群名/群号/触发内容）、群筛选、状态筛选（全部/未回复/异常）、空态
- **聊天主界面（会话详情）**：运行详情折叠卡、工具调用卡（成功/失败/运行中）、回复草稿、已发送气泡、错误复盘卡、冷却倒计时（实时跳动）、运行秒表（实时跳动）
- **设置页**：侧栏分区切换（桌面端/模型 API/聊天与节奏三个分区为完整实现，其余分区为占位）、主题预设卡（四张）、自定义颜色色板、亮度滑杆（真实生效）、界面缩放、主题文件导入区（含 theme.json 内容预览）
- 状态覆盖：已发言 / 运行中 / 等待中 / 出错 / 筛选空态 / 无选中空态

## 集成假设（与现有代码的边界）

1. **theme.json 完全走现有通道**：`设置 → 桌面端 → 界面 → 导入主题文件`，即 `modules/themes/impl.js` 的 `importTheme() → parseThemeText()`。三份文件均已用真实解析器实测通过（必填 `bg/bg2/accent/text` 齐全，共 8 色）。导入后写入 `data/themes/` 并立即应用。
2. **只透传颜色，不改形态**：现有 custom 通道仅覆盖 CSS 变量（`--bg/--bg-2/--bg-3/--accent/--text/--muted/--faint/--tool-accent`）。三套原型中的**形态细节**（A 的朱丝栏与衬线标题、B 的 HUD 角括号/网格底纹/等宽数字、C 的大圆角与暖光渐变）如需落地，应按现有 `data-ui-style` 机制（`mech` / `pixel` / `maid` 先例）新增对应样式分支——这属于核心样式改动，需另行评估，本次未动。
3. **布局与真实 UI 一一对应**：原型顶栏/标签页/`#view-sessions`（列表 + 详情）/`#view-settings`（侧栏 + 表单）的结构与 `ui/index.html` 对齐，类名尽量沿用（`session-item` / `settings-sidebar` / `settings-block` 等），降低后续移植成本。
4. **设计 token 同名映射**：三套原型 `:root` 中的 token 命名与 `ui/style.css` 一致，主题卡上的色值与各自 `theme.json` 一致。
5. **演示数据为虚构**：6 条会话样例仅用于状态覆盖演示，与真实运行数据无关。
6. **亮度/缩放**：原型内为真实交互（filter/zoom）；Electron 侧对应既有 `webContents.setZoomFactor` 与 brightness 实现，接入时替换即可。

## 验证记录（2026-09-26）

- `parseThemeText` 实测：三份 theme.json 均 **PASS**（id/name/colors 8 项全部解析合法）
- 无头浏览器冒烟：三套均通过——6 条会话渲染、会话/设置视图切换、状态筛选（异常→1 条）、搜索空态、暂停↔继续切换、错误工具卡/复盘卡/冷却倒计时/运行秒表节点全部存在
- HTML 结构检查：`<div>`/`<style>`/`<script>` 标签配对完整、`lang="zh-CN"`、含 `prefers-reduced-motion` 与 `:focus-visible`

## 无障碍与细节

- 全部交互元素可用键盘操作（Tab / Enter / Space），`:focus-visible` 焦点环
- `prefers-reduced-motion` 下关闭全部动画（脉冲、加载、光标闪烁）
- 图标为内联 SVG（无 emoji 图标、无图标字体、无外链）；`aria-label` 覆盖纯图标按钮
