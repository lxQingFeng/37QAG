# QQ Agent 主题文件规范 v1
# 目录：themes/
# 支持扩展名：.json  /  .theme.txt  /  .txt
# 导入：控制台 → 设置 → 桌面端 → 界面 → 导入主题文件
# 主题开关用的是「自定义主题」；导入后会立刻应用，并写入配置（两号互通）。

────────────────────────────────────────
一、颜色字段（都要写成 #RRGGBB 或 #RGB）
────────────────────────────────────────
bg          窗口底色
bg2         卡片 / 侧栏底色
bg3         次级块 / 输入槽底色
accent      主强调色（按钮、选中、滑块）
text        正文颜色
muted       次要文字（可选；不写则按 text 自动推）
faint       更弱的文字（可选）
tool-accent 工具名强调色（可选；不写则用 accent）

────────────────────────────────────────
二、推荐文件名
────────────────────────────────────────
my-theme.json
my-theme.theme.txt

────────────────────────────────────────
三、格式 A：JSON（推荐）
────────────────────────────────────────
{
  "format": "qq-agent-theme",
  "version": 1,
  "id": "my-theme",
  "name": "我的主题",
  "colors": {
    "bg": "#0c0c0e",
    "bg2": "#151517",
    "bg3": "#222224",
    "accent": "#f5a623",
    "tool-accent": "#ff7a00",
    "text": "#f4f4f5",
    "muted": "#a0a0a5",
    "faint": "#6e6e73"
  }
}

也允许把颜色直接平铺在顶层（兼容更旧的手写习惯）：
{
  "id": "my-theme",
  "name": "我的主题",
  "bg": "#0c0c0e",
  "bg2": "#151517",
  "bg3": "#222224",
  "accent": "#f5a623",
  "text": "#f4f4f5"
}

────────────────────────────────────────
四、格式 B：键值纯文本（.theme.txt / .txt）
────────────────────────────────────────
# 井号开头是注释
id=my-theme
name=我的主题
bg=#0c0c0e
bg2=#151517
bg3=#222224
accent=#f5a623
tool-accent=#ff7a00
text=#f4f4f5
muted=#a0a0a5
faint=#6e6e73

冒号也行：
bg: #0c0c0e

────────────────────────────────────────

────────────────────────────────────────
参考 Armoury Crate：近黑底 + 琥珀橙强调。
文件：themes/mech-orange.json

────────────────────────────────────────
六、白京玉 · 像素夜（内置预设）
────────────────────────────────────────
像素风雨夜咖啡馆：深蓝 #1a2744 + 暖琥珀 #e8a84c + 冰蓝 #6ba3d6
浅字 #e8f0ff。UI 形态 data-ui-style=pixel（硬边框，非液态玻璃）。
壁纸：themes/bijingyu-bg.png → ui/assets/bijingyu-bg.png
文件：themes/bijingyu-pixel.json

────────────────────────────────────────
七、注意
────────────────────────────────────────
· 必填：bg、bg2、accent、text（缺太多会拒绝导入）
· 亮色主题建议 text 用深色 #1d1d1f，避免看不清
· 深色主题 text 必须用浅色，并与 customText 一致，避免正文发黑
· 导入只会写到 themes/ 与当前界面配色，不改聊天逻辑
· 自带示例可直接复制改色
