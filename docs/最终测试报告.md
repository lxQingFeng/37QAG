## 四、收官冒烟发现并修复的 2 个 bug

**Bug 1：4 档（默认）唤醒捷径丢失显式召唤标记**（`src/prompt.js` resolveContextTier）
- 症状：默认 store.contextTier=4 下，@/叫名字/拍一拍的 `atMe/explicitResponse` 字段不随 tierResult 返回 → orchestrator 把明确召唤当成「主动插话」——本地 Jev 关闭时整批跳过（**群友 @ 了也沉默**，冒烟第一轮实测复现）；Jev 开启时也存在被插话判定否决的可能，违反产品铁律「被 @ 必回、不允许插话决策否决」。
- 既有测试盲区：只测了 contextTier=3 路径。
- 修复：4 档捷径补带 atMe/explicitAt/nameMention/pokeAtBot/explicitResponse/keyword 与对应 reason；普通消息仍为「全部响应」，上下文读取仍按 allCount，1~3 档路径零改动。
- 回归：stability-fixes-test.mjs 新增「4 档全读不丢显式召唤标记」（@/拍一拍/普通消息三种输入断言）。

**Bug 2：sessions.js 引用未导入的 DATA_DIR**（阶段二路径集中化漏网）
- 症状：会话 finish 时 #bumpTodayUsage 抛 `ReferenceError: DATA_DIR is not defined`，被 #persist 的 catch 误报成「**持久化失败**」；实际会话 JSON 已写出、用量台账已记，但 usage-today.json 永不落盘 → **当日用量统计恒为 0**，且每个会话结束都刷一条误导性 ERROR（冒烟日志实测）。
- 修复：`import { sessionsDir, DATA_DIR } from './paths.js'`（全库扫描确认其余 DATA_DIR 均为注释或已导入，此为唯一漏网）。
- 回归：新增 test/session-usage-test.mjs（create→finish 全路径：usage-today.json 写出、todayUsage 读回一致、会话留档存在）。

4. **Electron 桌面端 GUI**：沙箱无显示环境，桌面窗口/UI 交互未实测（headless 控制台 API 已全验）。
5. **多实例双号并发**：仅验证实例锁与端口错开的单实例逻辑，未真实双号同时在线。
6. **真实群聊长期行为**：拟人化提示词的实际口吻、记忆/情绪/健康系统的长程演化，需真机观察（沙箱只能验链路正确性）。
