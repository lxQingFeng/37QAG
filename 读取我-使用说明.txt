============================================================
  QQ Agent 整合版（便携）
  【一个 QQ 号】双击「启动-单号.bat」← 绝大多数人用这个
  【两个 QQ 号】双击「启动-双号.bat」（会一次起两个控制台）
  更详细的用法看同目录下的《读取我-使用手册.txt》（每个页面、每个开关都有）
============================================================

【零、我该点哪个启动脚本？】
  · 启动-单号.bat         你只有**一个** QQ 号 → 点这个。数据存 data\。
                          它**只**起号A —— 就算你以前配过第二个号（data-2\）也不会带起来。
  · 启动-双号.bat         你要同时跑**两个** QQ 号 → 点这个。**只开一个程序窗口**，
                          号B 由桌面壳作为独立核心拉起（顶栏出现账号标签页，点一下切换）。
                          第一次点它会自动生成 data-2\config.json（白名单是空的，
                          要先去号B 的控制台把群加上）。
  · 启动-单号-调试模式.bat  程序起不来、要看报错 → 点这个（前台跑、日志留在窗口里）。
  这三个脚本都是**启动完就自己关掉**的黑窗口；启动结果写在 launch-log.txt。
  想让它停住看输出：在命令行里加 /keep（例如 启动-单号.bat /keep）。

【一、第一次打开】
  1. 双击 启动-单号.bat（若杀毒软件拦截，选"允许"）。
  2. 程序会自己弹出窗口（就是控制台界面），不用手动开浏览器。
     想用浏览器看也行：http://127.0.0.1:3210/（端口被占用会自动往后找，
     真实地址打印在启动窗口里）。
  3. 在「设置 → 模型 API」里填你自己的 API Key（OpenAI 兼容：
     百炼/DeepSeek/智谱/OpenRouter…都行），选一个模型，保存。
  4. 在「设置 → 聊天白名单」里把你的 QQ 号 / QQ 群号加进白名单
     （有「选择群 / 选择好友」按钮，直接从 QQ 拉列表勾选）。
     **白名单为空时机器人不会理任何消息**，这不是坏了。
  5. 人设：默认是「小鲸鱼」角色卡；在「设置 → 人设」里挑模板或自己写。

【二、连 QQ】需要自己准备一个 OneBot 桥
  本包内置的 snowluma/ 是桥的程序本体**不带任何账号配置**。
  第一次使用：在控制台「QQ 连接」页点「启动 SnowLuma」，
  然后打开它打印出来的网页地址登录（用户名 admin，密码是它启动时
  打印在运行日志里的那串随机码），同意它的协议后扫码登录。
  ⚠️ 不要直接双击 snowluma\launcher.bat —— 那个脚本要你机器上装过 Node.js；
  从控制台启动走的是包内自带的 node.exe，什么都不用装。
  （QQ 协议端有风控风险，请自行评估；本项目只做消息处理，不碰账号安全。）

【三、内置的本地小模型（0.8B）】
  models/Qwen3.5-0.8B-Q6_K.gguf  +  runtime/llama/llama-server.exe
  它是一个**本地小模型**，用来做"要不要接话 / 该不该发表情 / 这句话是什么情绪"
  这类小判断（省云端 token，且断网也能判）。默认开机自动拉起，端口 18080。
  · 想用显卡加速：把设置里 localJev.exePath 改成
    runtime/llama-cuda/llama-server.exe（本包默认不含 CUDA 版，约 1.1GB；
    需要可让打包者用 --with-cuda 重新打包），并把 gpuLayers 调大。
  · 不想要它：设置里把 localJev.enabled 关掉即可，功能会退回云端/正则。

【四、附带的能力（12 个插件 + 9 个技能，共 21 个）】
  默认开（装上就能用）：
    禁言状态、图片格式兼容、发言人身份、思考模式适配、视频抽帧、
    计算器、文本工具、天气查询
  默认关（去控制台「扩展」页自己打开，多数要先装外部程序或填密钥）：
    · 世界与事件(life-system)：世界设定 + 日历 + 近况账本，填了才有效
    · 账号池(account-pool)：多账号轮询，填多个 API 账号
    · 主人识别(owner-identity)：填了主人 QQ 才生效
    · 语音转文字(speech-to-text)：要 whisper-cli + 模型，本地跑不上传
    · 视频下载(media-download)：要 yt-dlp / ffmpeg
    · 文生图(image-generate)：要填图片 API
    · 随机图 / 反查图片 / 记忆召回 / 梗库 / 表情备注
    · 会话记忆(conversation-memory) / 回复安全(reply-safety)：与核心功能重复，
      开着会双份注入，默认关；除非你确实想用扩展版实现
  插件的设置表单是**按插件自己的清单自动生成**的（支持下拉/开关/数字/多行文本/
  密码框/字段联动显示/只读项），不需要改界面代码；插件自己带 panel.html 的
  还会多一个「打开插件面板」按钮。

【五、隐私与对外请求（请先读这条）】
  · 本包**不含**任何聊天记录、记忆、日志或密钥（已整目录剥离）。
  · 会主动联网的功能：模型 API（你配的那个）、搜索/百科（web_search /
    external_lookup）、图片直链下载、B 站接口、天气接口，以及：
      - 反向搜图会把**图片上传**到公开搜图站/图床（saucenao/iqdb/百度识图等），
        默认关闭，开了才用；
      - 语音转文字默认关闭，启用后在本机跑 whisper，不上传；
      - 视频下载默认关闭，启用后在本机跑 yt-dlp。
  · 本地小模型只在 127.0.0.1:18080/18085 上跑，不外传数据。

【六、常见问题】
  · 双击没反应：看「启动-单号-调试模式.bat」的报错（它会保留窗口不关）；
    或先用 启动-单号.bat 的窗口日志排查。
  · 提示端口被占用：控制台会自动往后找端口，看窗口里打印的地址。
  · 机器人对谁都不理：先看「设置 → 聊天白名单」是不是空的
    （空名单 = 谁都不理，这是默认行为）；再看顶栏 OneBot 是不是绿点。
  · 想同时跑两个号：直接双击「启动-双号.bat」，什么都不用改。
      它是**一个窗口两个号**：号A 用 data\，号B 用 data-2\（由程序自己拉起，
      顶栏账号标签页切换）。两个号的群白名单**千万别重叠**，
      否则同一个群会被两个机器人各回一遍。
      ⚠️ 号B 要在 SnowLuma 里**自己有一套 OneBot 网络**（例如 HTTP 3010 / WS 3011）
      并绑到号B；号A 用默认那套（HTTP 3000 / WS 3001）。
      想再单开一个窗口跑号B（老玩法）：另开 cmd 执行
        set QQ_AGENT_PROFILE=2 && npm start
      两种玩法别同时用（同一个 data-2\ 会被两个进程抢）。
  · 换电脑：整个目录拷走即可，data\ 里是全部个人数据。
