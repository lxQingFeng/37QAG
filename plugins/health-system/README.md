# 健康系统 插件 (health-system)

> 给人设用的**生存状态模拟**：会生病，也会练琴、养猫、交朋友。
>
> 名字里的「健康」是支点而非边界 —— 插件真正在做的是「身体如何反向影响生活」：宠物掉毛推高过敏负荷、
> 夜行物种磨掉睡眠、身体状况决定心情与归属感。所有状态只影响对话语气，不显示数值。

## 基础需求深化（v7.0）

这一层给 13 个基础维度加上「身体的连锁账」，让数值不再是各自独立的孤岛。

### 一、维度间连锁反应

当某个基础维度跌破阈值，会持续拖累其他维度（共 29 条规则，可在配置里整体关闭或调节强度）：

| 触发条件 | 连锁后果 |
|----------|----------|
| 缺水（口渴度 < 30） | 疲劳↑、心情↓、精神疲劳↑（注意力涣散） |
| 饥饿（饱食度 < 30） | 心情↓、精力↓、抵抗力↓ |
| 精力见底（< 30） | 精神疲劳↑、专注力↓ |
| 过度疲劳（< 30） | 抵抗力↓、健康↓ |
| 缺觉（睡眠需求 < 30） | 疲劳↓、专注力↓、焦虑↑ |
| 压力过大（< 30） | 睡眠↓（越压越睡不着）、心情↓、抵抗力↓ |
| 心情低落（< 30） | 精神疲劳↑、抵抗力↓ |
| 孤独（< 40） | 心情↓、归属感↓ |
| 社交匮乏（< 30） | 孤独↓、归属感↓ |
| 归属缺失（< 30） | 安全感↓、心情↓ |
| 不满足（< 30） | 心情↓、精力↓ |
| 环境不适（< 30） | 心情↓ |
| 健康透支（< 30） | 疲劳↓、抵抗力↓ |

越低于阈值，连锁越强（强度 ×1.0 ~ ×1.6）。

### 二、六项深层生理亚成分

| 亚成分 | 说明 |
|--------|------|
| 🧂 电解质 | 过低会「喝再多也不解渴」（白水吸收打折、口渴度上限被压）；高温出汗加速流失，喝白水会稀释 |
| 🍔 热量盈余 | 吃太饱会累积并顶得难受，长期沉积为脂肪（悄悄长胖）；饥饿与运动可消耗 |
| 🧠 精神疲劳 | 白天用脑与社交的累积，靠睡眠/小憩/冥想/放松恢复；过高会拖垮专注力 |
| 💞 亲密需求 | 浅层社交补不上，需要深聊、陪伴、聚会才能真正填满 |
| 🎢 情绪波动 | 情绪稳定度低时上升，波动大容易无端烦躁 |
| 🏋️ 体力储备 | 运动的底子，越高越经得起熬夜与劳累 |

### 三、非线性恢复与溢出

- **越缺越补得动**：喝水/吃饭的吸收效率随缺口增大而提高（缺口 100 时全额吸收，接近满值约 55%）
- **边际递减**：快满的时候，喝也喝不下、吃也吃不动
- **溢出转化**：吃撑的部分转为热量盈余（并让舒适度下降）；白水喝多会稀释电解质
- **恶性循环**：电解质低 → 喝白水不解渴且越喝越低 → 必须靠电解质饮料打破

### 四、新增动作

| 动作 | 作用 |
|------|------|
| 水平衡检查 | 查看水分/电解质/体力储备，并给出补水建议 |
| 补充电解质 | 喝电解质饮料，快速补上并解除「喝不解渴」（花费金钱） |
| 身体信号 | 扫描六项深层生理 + 当前所有连锁预警 + 体感异常项 |


## 生命节律与身心生态（v8.0）

七层互相咬合的新系统，让身体从"一堆各自衰减的数字"变成有内在因果的生态。

### 一、昼夜节律（🕰️）

内置五条 24 小时真实生理曲线，按分钟级线性插值：

| 曲线 | 形态 |
|------|------|
| 精力 / 警觉度 | 上午 9-11 点双峰登顶，13-15 点午后低谷，16-19 点次峰，凌晨 3-5 点谷底 |
| 皮质醇 | 凌晨最低，6-8 点陡升达峰（晨醒反应），之后一路下行 |
| 褪黑素 | 22-2 点为峰，白天接近 0 |
| 基础体温 | 凌晨 4-5 点最低，16-18 点最高（振幅约 0.5℃） |

六个节律段各有专属表现：**深夜低谷 / 晨间唤醒 / 上午高峰 / 午后低谷 / 傍晚次峰 / 夜间沉静**。

- **状态衰减不再是"白天/夜晚"二值**，而由曲线驱动：深夜精力几乎在回血、上午消耗最快；夜间睡眠需求掉得最狠。
- **激素基线跟随曲线**：皮质醇会自己"晨高夜低"、褪黑素"夜高昼低"，压力与失眠表现为偏离基线。
- **生物钟相位偏移**（`circadianOffsetInitial` 叠加睡眠生物钟偏移）：正值 = 夜猫子型，生理节律比钟表晚，同一钟点拿到的精力曲线更低；负值 = 早鸟型。建议睡眠窗口也随之平移。

### 二、肠道菌群（🦠）

六项菌群：双歧杆菌 / 乳酸菌 / 拟杆菌 / 厚壁菌 / 菌群多样性 / 肠道屏障。

- 综合评分决定**营养吸收率（70%-120%）**、**血清素基线（肠脑轴）**、**免疫调节**与**消化舒适度**。
- **抗生素会无差别重创菌群**（多样性掉得最狠，屏障相对抗打），需要靠益生菌与高纤维饮食慢慢补回。
- 屏障跌破 38 且免疫偏低 → 肠漏症；综合跌破 40 → 菌群失调；菌群差 + 压力大 → 肠易激综合征。

### 三、过敏系统（🤧）

八种过敏原：花粉 / 尘螨 / 霉菌 / 宠物皮屑 / 海鲜 / 花生 / 乳制品 / 冷空气，各有 1-5 级敏感度。

- 过敏谱启动时随机生成：**家族有过敏史 ×3、特禀体质 ×2.5** 概率加成。
- **吸入与物理类**随环境实时触发：春秋花粉季、AQI 高 → 尘螨、湿度 >78% → 霉菌、气温 <8℃ → 冷空气；**食物类**在进食时独立掷骰。
- 累加为**过敏负荷**（0-100），持续压低舒适度、睡眠质量与专注力，并消耗免疫。
- 负荷越阈值发病：**过敏性鼻炎（45）→ 荨麻疹（62）→ 哮喘（72）→ 过敏性休克（88，危重）**。

### 四、社交关系网（📇）

把旧的"羁绊"升级为五类关系：家人 / 恋人 / 挚友 / 同事 / 群友，各有亲密度上限、疏远速率与深聊收益。

- 首次运行播下初始关系种子（妈妈 / 爸爸 / 挚友，数量可配置）。
- 亲密度**会随时间自然疏远**（12 小时内有互动则不衰减）；跌破 40 开始积攒矛盾，积怨会加剧孤独感。
- 关系网反哺归属感、安全感与亲密需求满足度。
- **深聊**大幅提升亲密度与亲密感、削减积怨，并即时缓解孤独与压力；**和解**专门用来化解积怨。

### 五、生物年龄（🧬）

九类因素加权推算生理年龄，与实际年龄的差值即"身体透支程度"：

| 因素 | 依据 |
|------|------|
| 器官健康 | 八大器官平均健康度 |
| 代谢指标 | 检验指标综合评分 |
| 生活方式 | 饮食 / 运动 / 睡眠质量 |
| 生活习惯 | 吸烟 / 饮酒 / 熬夜 / 久坐 |
| 心理状态 | 焦虑 + 抑郁 − 情绪稳定 |
| 肠道菌群 | 菌群综合评分 |
| 营养均衡 | 八大营养素平均 |
| 外伤损耗 | 累计受伤次数 + 未愈伤口 |
| 过敏炎症 | 当前过敏负荷 |

差值分档：**逆龄奇观（≤-8）/ 保养得宜（≤-3）/ 表里如一 / 略有透支 / 明显老化 / 未老先衰（≥14）**，并联动「冻龄体质」成就。

### 六、医保系统（🧾）

| 方案 | 年费 | 报销 | 年度上限 |
|------|------|------|----------|
| 无医保 | ¥0 | 0% | — |
| 居民医保 | ¥120 | 50% | ¥2000 |
| 职工医保 | ¥400 | 75% | ¥6000 |
| 商业保险 | ¥1200 | 90% | ¥20000 |

- 全部医疗支出（看病 / 住院 / 化验 / 抽血 / 影像 / 疫苗 / 心理咨询 / 急诊 / 买药 / 电解质饮料 / 褪黑素 / 消毒 / 戒瘾）都走医保结算，**超出额度部分自付**。

- 累计医疗花费按**总支出**（自付 + 报销）统计，方便衡量医保价值。

### 七、健康大事记（📜）

自动记录关键节点：首次患病、过生日、解锁成就、办理医保、检测出过敏原等（上限 60 条，倒序可查），供对话时回忆引用（"你上次过敏还是三个月前的事"）。

## 日常生活（v11.0）

这一版补的是三件「早该有却没有」的事：**天气没有体感、吃饭没有选择、钱没有去处**。

### 一、穿衣（🧥）

此前 `env` 里躺着 `tempC / humidity / aqi / uv / weather`，但它们只影响疾病易感与化验指标 ——
天冷不提醒加衣、暴晒不用防晒，`uv` 更是只被 `getUvLevel()` 拿去显示天气文字，纯装饰。

现在天气有了**冷热偏差**。

> 这里刻意不用「体感 = 气温 + 保暖」的线性模型 —— 22℃ 穿长袖（保暖 26）会算出体感 48℃，
> 被判成「热到冒烟」。衣物的作用是把**可接受的气温区间平移**，而不是无条件加温。

```
冷热偏差 = 外面气温 − 这身衣服的舒适点
（淋湿会让保暖打折 → 舒适点整体下移 wet × 0.06，所以湿衣服更怕冷）
```

| 衣物 | 舒适气温 | 保暖 | 风格 | 备注 |
|---|---|---|---|---|
| 🩳 睡衣 | 26℃ | 0 | 居家 | 最舒服，但见不得人（社交形象 −8） |
| 👕 短袖 | 29℃ | 6 | 休闲 | 夏天标配 |
| 👔 长袖休闲 | 22℃ | 26 | 休闲 | 春秋常服 |
| 🧥 薄外套 | 17℃ | 46 | 利落 | 早晚温差大 |
| 🧣 厚外套 | 11℃ | 68 | 利落 | 深秋到初冬 |
| 🧤 羽绒服 | 1℃ | 92 | 利落 | 零下也能扛 |
| 🦺 冲锋衣 | 15℃ | 40 | 运动 | **防水**，雨天不淋湿 |
| 🎽 运动装 | 24℃ | 16 | 运动 | 运动有加成 |
| 🤵 正装 | 21℃ | 34 | 正式 | 见人时社交形象 +9，但在家穿着难受 |

偏差落在哪一档决定后果：

| 偏差 | 状态 | 舒适度 | 风险 |
|---|---|---|---|
| ≤−22℃ | 冻得发抖 | −14 | 受凉概率 55% |
| ≤−12℃ | 有点冷 | −6 | 25% |
| ≤−6℃ | 偏凉 | −1 | 6% |
| −6 ~ +6℃ | **刚刚好** | +3 | 无 |
| >+6℃ | 有点热 | −3 | 中暑 8% |
| >+12℃ | 热得难受 | −8 | 30% |
| >+22℃ | 热到冒烟 | −15 | 55% |

- **雨天**穿不防水的衣服会持续淋湿，湿衣服几乎不保暖，湿透还会压免疫力
- **紫外线 ≥6** 且没防晒，白天在户外会累积 `sunExposure`，涨满就**晒伤**（新疾病）
- 不带参数问一句，会给当天穿搭推荐（挑**舒适点最贴近今天气温**的那件；下雨则优先防水款）

### 三、房间与家务（🏠）

`computeAllergyLoad` 里尘螨的判定原来只认室外空气：

```js
if (aqi > 80) add('dustmite', 1.4, '空气差');
else add('dustmite', 0.5, '日常环境中的尘螨');
```

可尘螨住在床单被褥里，最相关的变量是**多久没打扫**。现在补上了：

| 整洁度 | 尘螨因子 |
|---|---|
| <25 | **×2.1** |
| <45 | ×1.55 |
| <65 | ×1.15 |
| ≥85 | ×0.75 |

晒被子额外再乘 0.55（余效 >40 时），所以「晒被子除螨」是真的有用。

可做的家务：**打扫**（整洁 +40）／**洗衣服**（洁净 +48）／**晒被子**（+8 整洁、驱螨）／**洗碗**／**请保洁**（¥130 一次全包）。

整洁度还会因**宠物掉毛**加速下降 —— 这条链终于闭环：

```
宠物掉毛 → 房间变脏 → 尘螨因子 ↑ → 过敏负荷 ↑ → 过敏性鼻炎
```

### 一、发薪日（💼）

两者节奏完全不对齐 —— 现实里是**月中旬紧、发薪日松**，滴灌出不来这种起伏。

| 项目 | 说明 |
|---|---|
| 月薪 | 默认 **¥3600**，每 30 天一次性到账，与账单同周期 |
| 首笔 | 开局 10 天后到账（不用干等一个月，像是月中入职） |
| 到账效果 | 安全感 +8、压力值 +6（这两个维度都是「高=好」），并记入大事记 |
| 零钱 | 原 `moneyAllowance` 降级为**零钱杂项**，默认 ¥1/小时（约 ¥720/月） |

### 二、打工（💪 卖时间）

收入不再掷骰子，改由**身体状态**决定：

```
收入 = 工种基准价 × 身体状态系数(0.55~1.45) × 运气(0.9~1.1)
```

身体状态系数由六项加权：健康 26% · 精力 24% ·（100−疲劳）20% · 饱食 12% · 水分 8% · 心情 10%。
**状态好手脚麻利赚得多，饿着肚子或带着疲劳去干就只值半价。**

| 工种 | 基准价 | 冷却 | 精力 | 门槛 | 特点 |
|---|---|---|---|---|---|
| 💪 体力活 `labor` | ¥95 | 6 小时 | −22 | — | 搬货装卸，最耗身体（上肢劳损 +2.2） |
| 🛵 跑腿 `errand` | ¥72 | 4 小时 | −14 | — | 送外卖取快递，扣水分最多 |
| 🖊️ 细活 `skilled` | ¥148 | 8 小时 | −12 | 最高爱好等级 ≥4 | 校对录入翻译，费脑子不费力气 |

**营养素的方向陷阱**：`sodium`（控盐）/ `sugar`（控糖）/ `fat`（脂肪均衡）三项的语义都是
**高 = 好**，所以泡面/快餐这类高油高盐的菜在这里必须是**负数**，而不是「盐分 +3」。

### 二、慢性病长期管理（♻️）

旧模型里，三处治疗逻辑都写着 `if (isChronic(d)) diseaseStages[d] = '初期'` ——
等于「高血压」这类病**永久挂在疾病列表上**，既不恶化也不好，所谓长期管理毫无意义。

新模型把三个抓手交给玩家能主动经营的指标：

```
生活方式达标 = 饮食 ≥ 65 且 运动 ≥ 55 且 睡眠质量 ≥ 60
```

- 达标时每次治疗成功累积 1 点控制进度（`CHRONIC_CONTROL_NEED = 3`）
- 攒满 3 次 → 进入 **21 天缓解期**（`REMISSION_DAYS`），期间从疾病列表移出且**不会复发**
- 缓解期到期，若诱因仍在，疾病会卷土重来（第二轮的进度从 0 重算）
- 生活方式一旦垮掉，已攒的进度按每周期 −0.25 **倒退**

### 反哺身体

异常指标会在 `applyVitalImpact` 里反向加重负担：蛋白尿磨肾（kidney）、高皮质醇磨脑（brain）、
INR 异常提示凝血风险、高胰岛素提示代谢综合征、CRP/血沉升高持续消耗健康值。
对话情绪提示同步扩展（「尿里泡沫多、腰酸」「情绪紧绷、睡不好也吃不下」「腿肿胸闷」等）。

### 报表展示

图片报表的检验指标卡片从只显示 6 项关键值重构为**全量分组展示**：
10 个分组各成子卡片，每项带 emoji、名称、数值、单位与参考范围，异常项橙/红高亮。
`blood_test`（抽血化验）与 `vital_check`（指标速览）输出自动覆盖全部 36 项。

### 着色规则

进度条颜色按"这个值是不是好消息"来定，而不是单纯看大小：

- 绿色（好）/ 蓝色（一般）/ 橙色（偏差）/ 红色（危险）
- `发烧度`、`焦虑度`、`睡眠负债`、`热量盈余`、`精神疲劳`、`情绪波动`、`成瘾度`、`抑郁度` 这类
  **越高越糟**的维度会自动反转：发烧 90 分是红色，不是绿色。

### 降级策略

图片是增强而非唯一路径，发送通道按**三层兜底**，不会出现"发了 /健康 却没反应"：

1. **直发**：钩子上下文自带发送通道（宿主直传，或此前调用过本插件任何工具已暂存）→ 直接渲染发图，不等模型；
2. **桥接**：钩子没有发送通道（部分宿主钩子不传 `sender` 且本次开机还没调用过工具）→ 注入指令让模型调用「健康图片报表」工具来发 —— 工具执行时宿主一定传全量上下文，工具失败时它自己返回文字版报告；
3. **文字**：图片功能被配置关闭 → 纯文字报告。

此外截图返回空图时会先自动换另一种渲染路径重试一次。每层降级插件日志里都会写明原因，可用 `reportImageEnabled` 关掉图片直接走文字。

## 疾病系统

### 疾病阶段

| 阶段 | 健康值衰减加成 | 治疗成功率 |
|------|------------|----------|
| 初期 | +1/次 | 50% |
| 中期 | +2/次 | 35% |
| 晚期 | +3/次 | 20% |
| 危重 | +5/次 | 10% |

### 疾病进展

- **可自然恢复**的疾病（感冒、咳嗽、头痛等）：阶段逐渐减轻，可能自愈
- **会自然恶化**的疾病（发烧、中暑、流感等）：阶段逐渐加重，需尽快治疗
- **需要治疗**的疾病（抑郁、关节炎等）：不会自然变化，必须看病

### 季节性疾病

按当前月份自动判断季节（春 3-5 / 夏 6-8 / 秋 9-11 / 冬 12-2），只触发当季疾病。

### 治疗

`看病治疗` 工具：符合现代医疗体系，疾病阶段越严重治疗成功率越低，需要多次治疗才能痊愈。

## 情绪影响

健康系统**不直接发送数值**，而是通过系统提示让 LLM 在对话中自然体现状态：

- 状态良好 → 正常情绪
- 状态危险/严重 → 回复体现口渴、饥饿、疲惫、难受等情绪
- 生病 → 回复体现相关症状（不说出具体病名）

## 人设卡初始值

在人设卡中添加健康初始值（可选，不写则默认 80）：

```
## 健康初始值
- 口渴度: 90

- 精力值: 50
- 健康值: 85
- 心情值: 70
```

首次对话时自动从人设卡解析，之后以文件持久化状态为准。

## 使用场景

1. **角色扮演** - 让机器人有完整的人设感
2. **互动养成** - 用户照顾机器人，提升机器人状态
3. **情感陪伴** - 心情值和孤独感反映机器人情绪状态
4. **社交模拟** - 模拟真实的社交需求

## 图片报表的实现方式（v7.1）

- 报表 HTML 完全由插件本地生成（`buildReportHtml()`），不联网、不依赖任何三方绘图库。
- 转 PNG 走宿主 Electron 的 `BrowserWindow` + `capturePage()`：先按内容真实高度调整窗口，
  再截图取字节，最后 `toPNG()`。因此字体沿用系统字体，中文与 emoji 都能正常渲染。
- 由于宿主对 Chromium 做了强限制（`disableHardwareAcceleration` + `--disable-gpu` +
  `--disable-software-rasterizer` + `--no-sandbox`），单一截图路径有偶发抓空的可能，
  所以会**先用隐藏窗口、失败再换离屏渲染**各试一次；两次都失败才降级文字。
- 生成的 PNG 落在系统临时目录 `%TEMP%\qq-agent-health-report\`，只保留最近 3 张，自动清理。
- 发送优先传本地文件路径（协议端自己读盘，HTTP body 只有约 100 字节），
  同时附带 base64 作为回退，避免协议端与本机不在同一台机器时发不出去。

## 注意事项

1. **状态持久化** - 状态保存在 `health-data.json`，重启后恢复
2. **全局状态** - 所有群共享同一份健康状态（单例）
3. **图片报表** - 依赖宿主 Electron 环境；若日志里出现"图片报表失败，降级为文字报告"，说明当前环境渲染不可用，功能会自动退回文字版，不影响使用
3. **人设卡初始化** - 只在首次对话时解析，之后以持久化状态为准
4. **配置状态值** - 修改【状态】组的值会立即应用到机器人当前状态
